## Project Description

Metswako's Delicious Corner is a restaurant and
takeaway website designed to provide customers with
information about the business, menu, services and
contact details.


## Website Pages

The website consists of five main pages:

1. Home
2. About Us
3. Products
4. Enquiry
5. Contact


## Technologies Used

- HTML5
- CSS3
- JavaScript


## Website Features

- Responsive website design
- Navigation menu
- Restaurant information
- Product/menu section
- Food images
- Enquiry form
- Contact form
- JavaScript form interaction
